# 열방약국 현금정산 — 설치 안내

약사님 Gmail 계정 **하나만** 로그인하고 데이터를 읽고 쓸 수 있는 웹사이트입니다.
교회 출석부 앱과 같은 방식(GitHub Pages + Firebase)이지만, 약국 전용 Firebase 프로젝트를 **새로** 만들어 교회 데이터와 완전히 분리합니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (보안 정책 CSP 포함) |
| `app.js` | 정산 프로그램 본체 |
| `fb.js` | Firebase 로그인·저장 연결 |
| `firebase-config.js` | **직접 수정**: Firebase 설정값, 허용 Gmail 주소 |
| `firestore.rules` | **Firebase 콘솔에 붙여 넣을** 보안 규칙 |

## 1. Firebase 프로젝트 만들기 (약 10분)
1. https://console.firebase.google.com 에서 **프로젝트 추가**를 누르고 이름을 정합니다 (예: `yeolbang-pharmacy`). Google 애널리틱스는 꺼도 됩니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google**을 켜고 저장합니다.
3. **Authentication → 설정 → 승인된 도메인**에 `nuruk21.github.io`를 추가합니다. (`localhost`는 기본으로 들어 있습니다.)
4. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
   - 위치는 **asia-northeast3 (서울)**을 고릅니다.
   - **프로덕션 모드**로 시작합니다.
5. Firestore의 **규칙** 탭에서 기존 내용을 모두 지우고 `firestore.rules` 내용을 붙여 넣은 뒤 **게시**합니다.
6. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(</>)**을 누르고 앱을 등록합니다. 화면에 나오는 `firebaseConfig` 값을 복사합니다.

## 2. 설정 파일 수정
`firebase-config.js`를 열고 아래를 바꿉니다.
- `firebaseConfig`: 방금 복사한 값으로 교체합니다.
- `OWNER_EMAIL`: 로그인할 Gmail 주소입니다. 기본값은 `nuruk21@gmail.com`입니다.

> 다른 Gmail을 쓰신다면 `firestore.rules` 안의 `'nuruk21@gmail.com'`도 **같은 주소(소문자)**로 바꾼 뒤 다시 게시하세요. 두 곳이 다르면 로그인은 되어도 데이터를 읽지 못합니다.

## 3. GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다 (예: `yeolbang-cash`).
2. 파일 5개를 모두 올립니다. README는 올리지 않아도 됩니다.
3. **Settings → Pages → Branch: main / (root)**를 선택하고 저장합니다.
4. 1~2분 뒤 `https://nuruk21.github.io/yeolbang-cash/`로 접속해 구글 로그인을 합니다.

## 보안 구조
- **구글 로그인 + 이메일 확인**: Gmail 주소가 정확히 일치하고, 구글로 로그인했고, 이메일이 인증된 계정만 통과합니다.
- **서버 측 차단(가장 중요)**: 화면 코드를 누가 고치더라도 Firestore 보안 규칙이 서버에서 다른 계정의 읽기·쓰기를 모두 거부합니다. 저장되는 항목, 금액 범위, 글자 수도 서버에서 검사합니다.
- **데이터를 기기에 남기지 않음**: 장부는 메모리에만 올려 두고 브라우저 저장소에는 쓰지 않습니다. 로그아웃하면 화면의 데이터도 지워집니다.
- **자동 로그아웃**: 기본 설정에서는 브라우저를 닫으면 로그아웃됩니다. 30분 동안 쓰지 않아도 자동으로 로그아웃됩니다. "로그인 유지"는 개인 휴대폰에서만 켜세요.
- **CSP·검색 차단**: 허용한 Google/Firebase 주소 외의 스크립트는 실행되지 않습니다. 검색엔진에도 노출되지 않도록 설정했습니다.
- GitHub에 올라가는 `firebaseConfig` 값은 공개되어도 괜찮은 식별 정보입니다. 데이터는 위의 보안 규칙이 지킵니다.

## 꼭 권장하는 것
- **구글 계정 2단계 인증**을 켜 두세요. 이 사이트의 보안은 결국 Gmail 계정 보안과 같습니다.
- **백업**: 프로그램의 **백업** 메뉴에서 한 달에 한 번 이상 `.json` 파일을 받아 PC나 USB에 보관하세요. 같은 화면에서 복원할 수 있습니다.
- 카카오톡 안에서 링크를 열면 구글 로그인이 막힙니다. 크롬이나 사파리로 여세요.

## 사용 요령
- **요양원 카드 결제**: ③ 외상·요양원에서 해당 요양원을 고르고 **수금 → 카드**로 입력합니다. ② 오늘 매출 카드 칸에는 넣지 않습니다(중복 방지).
- 마감한 날은 입력이 잠깁니다. 고칠 때는 **마감 해제**를 누르세요.

## 마감 화면 사진 자동 입력 (AI)
② 오늘 매출의 **📷 마감 화면 사진으로 자동 입력** 버튼을 누르거나, PMIT3000 약국통계 화면을 캡처한 뒤 사이트에서 **Ctrl+V**를 누르세요. AI(Gemini)가 조제·일반약의 현금/카드 금액을 읽어 채웁니다. 적용하기 전에 화면 숫자와 한 번 대조하세요.
- 설정: Firebase AI Logic(Gemini Developer API)과 App Check(reCAPTCHA)를 켠 뒤, `firebase-config.js`의 `APP_CHECK_SITE_KEY`에 사이트 키를 넣습니다.
- 사진은 Google Gemini로 보내져 읽힙니다. 무료 사용 범위에서는 Google이 입력 내용을 서비스 개선에 쓸 수 있으니, **환자 이름이 나오는 화면은 올리지 말고** 통계 화면만 올리세요.
